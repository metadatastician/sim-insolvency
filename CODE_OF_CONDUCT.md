# Code of Conduct

Participation must be respectful, accessible and evidence-minded. Harassment,
discrimination, doxxing, learner shaming, misuse of fictional scenarios as
legal advice, and misrepresentation of assessment status are unacceptable.
Maintainers may remove harmful content or participation and will preserve
confidentiality where safety permits.

## Reporting

Report Code of Conduct concerns through the same private channel `SECURITY.md`
uses for the `metadatastician` estate: a private GitHub security advisory on
this repository (`https://github.com/metadatastician/sim-insolvency/security/advisories/new`).
Include enough detail for a maintainer to act; confidentiality will be
preserved where safety permits.
