and are accessed through narrow ports. Estate repositories are not vendored.
The exact local revisions inspected during design are recorded below; they are
not automatically the revisions selected for a distributable release.

== Runtime profiles

`offline`::
Pure local deterministic execution with the file-backed `VeriSimPort` test
adapter and no group transport. This is the reference replay profile.

`local-verisim`::
Local kernel plus a pinned VeriSimDB service on loopback. No cloud account or
telemetry.

`group`::
The local-verisim or offline profile plus an explicitly enabled Burble room.
Burble data never bypasses command validation.

`standalone`::
Release directory or Wolfi OCI image containing the native kernel, static shell,
scenario/rule assets, licence and limitations. It runs without network access
or an external estate checkout.
