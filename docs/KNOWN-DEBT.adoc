= Known Debt
:toc: left

This is the honest counterpart to the claims in
`.machine_readable/descriptiles/STATE.a2ml`. That file states what the
project claims to be true; this register states what is still wrong, still
missing, or knowingly accepted. Every item below is in exactly one of three
states: `open` (not addressed), `accepted` (addressed by a decision not to
fix, with the reason given), or `resolved-<PR>` (closed, with the PR that
closed it). Nothing here is legal advice, a professional qualification, or
accredited CPD — see README and the authority-pack disclaimers for the scope
of that limitation.

Debt is organised by category. Within a category, IDs are stable once
assigned; do not renumber a resolved item, extend its status instead.

|12 files carry the SPDX identifier on line 2, not line 1, because line 1 is

than assume the identifier is always line 1 (see the estate rule: past

|11 shell scripts under `tools/` (e.g. `tools/check-hidden-truth.sh:2`) plus
`shell/index.html:2`
|accepted — shebang/doctype-first is the ruling; not a defect

[NOTE]
====
DEBT-CI-007 is the reason this register exists. The defect was introduced by a
merged pull request whose own checks could not report it, sat undetected for two
days, and was found only by validating the lockfile by hand during a
documentation pass. A gate that cannot report its own failure is worse than no
gate, because it is trusted.
