== Status and method

This is the architecture gate for Sim Insolvency. It was created before the
application scaffold or implementation. The revisions below are the exact local
commits inspected on 2026-07-29. A dirty, ahead, behind, or non-default-branch
checkout is evidence about that checkout, not permission to update or clean it.
No dependency working tree was mutated.

The inspection covered repository metadata, build files, readiness statements,
public interfaces, examples, ABI/FFI sources, test contracts, and local tool
availability. Claims are deliberately narrower than repository aspirations.

[IMPORTANT]
====
Sim Insolvency is an educational simulation and assessment system. It is not a
law firm, insolvency practice, live case-management system, legal advice,
statutory authorisation, regulated qualification, JIEB result, or accredited
CPD unless a competent external body separately approves it.
====

== AffineScript findings

=== Syntax and packages

The compiler consumes `.affine` modules. The inspected estate contains records,
variants, pattern matching, functions, `linear` types, quantity annotations
(`@linear`, `@erased`, `@unrestricted` and `:1/:0/:omega`-style sugar),
`extern fn`, effects, module imports and mutable forms. Syntax must be copied
from compiling in-tree examples, not inferred from ReScript-shaped migration
files in Burble.

The compiler is an OCaml/Dune package (`affinescript.opam`). The repository's
real compiler recipes are `dune build`, `dune runtest`, `dune fmt --check` and
`dune exec affinescript -- ...`. The root README install/compile commands are
unfinished placeholders.

=== Ownership and affine guarantees

Quantity checking is wired into the CLI. Core ownership rejects use-after-move,
double use and several escaping/conflicting borrow cases. The Polonius-style
region solver is not complete. For Sim Insolvency this supports owned command
and envelope values but does not justify placing complex shared mutable
projections or host-resource management entirely in AffineScript yet.

=== FFI and WebAssembly

Core WASM supports cross-module imports and maps `extern fn` to WASM imports.
The typed-wasm producer contract is the `typedwasm.ownership` custom section
plus the AffineScript boundary verifier. It is not invoked as a generic
`--typed-wasm` target. The project will therefore keep host imports small,
length-explicit and ownership-explicit, and verify the resulting carrier rather
than invent a build flag.

== Estate conventions

The inspected projects consistently use:

* code under PMPL-2.0-or-later and prose under PMPL-2.0-or-later, with per-file SPDX tags;
* RSR metadata, `0-AI-MANIFEST.a2ml`, contractiles/descriptiles, governance,
  security policy and `just`;
* Idris2 for proof-bearing ABI definitions and Zig for conventional FFI;
* explicit readiness and proof-debt statements;
* append-only ADRs;
* Guix-oriented reproducibility in the RSR template.

Sim Insolvency applies PMPL-2.0-or-later uniformly to original code,
documentation, and fictional scenario material. The clean licence blob is
pinned to Palimpsest commit `6f83592`; the later inspected working-tree copy
contains erroneous mechanical identifier substitutions and was not copied.
Third-party authority texts are citations, not copied training material or
bundled law.

== Decisions and blockers

. The event ledger is the portable authority; VeriSimDB persists and indexes
  ledger entities but cannot redefine them.
. Assessment hidden reality is excluded from learner artefacts. A local
  facilitator/kernel process owns it.
. The AffineScript compiler is principal but experimental. Zig is a temporary
  executable boundary, not a language substitution.
. typed-wasm is a verified carrier contract, not a label applied to generic
  WebAssembly.
. Gossamer is a shell only.
. Burble is optional transport only.
. SNIFS is not applicable to Phase A.
. Hexadeca integration is blocked pending a real repository/package.
. Legal rule content starts provisional and cannot support a professional
  certification claim.
. Guix is authoritative. No `flake.nix` will be added.
. The standalone bundle contains the kernel, shell, public scenario/rule assets,
  licence and limitations; it needs no network service. External estate
  integrations remain optional capability upgrades.
. ECHIDNA receives proof obligations and returns receipts through a port. A
  prover result cannot become a legal authority or mutate accepted case events.
. The immediate container surface is OCI/Wolfi via nerdctl. Stapeln metadata is
  future-facing and cannot be described as verified deployment yet.

== Reversal conditions

Ports may become direct dependencies only after a pinned upstream release
provides a stable, tested surface compatible with this repository's ownership,
error-totality, offline and deterministic-replay requirements. Any such change
requires an ADR update, conformance tests and a dependency revision change.
