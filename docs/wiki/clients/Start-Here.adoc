== Current proposition

Sim Insolvency is intended to provide repeatable, evidence-rich practice and
assessment using fictional cases. Its design supports local operation,
source-linked debrief, deterministic replay, pseudonymous portfolios and
separation between learner competence and case outcome.

The present build is pre-alpha. It has not undergone practitioner validation,
independent security assessment, accessibility conformance testing,
psychometric validation, accreditation or production service assurance. No
price, service level, implementation date, data-processing commitment or
accreditation claim is made by this page.

An institutional pilot should proceed only after G6 evidence is accepted and
with a written pilot protocol covering purpose, cohort, facilitation, data,
support, incident handling, evaluation and the non-qualification boundary.
