== Working model

The repository is Guix-first and PMPL-2.0-or-later throughout. AffineScript is
the principal domain-facing language; executable gaps sit behind versioned Zig
ports. Idris2 owns machine-checked ABI invariants. The deployment intention is
typed-wasm. Verisim is the persistence target, Gossamer the shell, Burble the
collaboration transport, and `HexadecaPort` the stable unified API boundary.

The event ledger is authoritative. Commands are validated before events are
accepted. Projections are disposable. Scenario reality, potential evidence,
disclosed evidence, learner beliefs and normative state remain separate.

Start with `just doctor`, then `just check`. `just docs-health` validates this
wiki. Do not add Python, TypeScript, Node, React, C FFI, Nix or an untyped
JavaScript implementation. Read link:../programme/Known-Limitations.adoc[Known
Limitations] before treating an estate adapter as complete.
