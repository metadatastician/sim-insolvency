== Role and boundary

The facilitator controls room admission, the shared case clock and authorised
reveals. Discussion, proposals, votes, objections and dissent may be exchanged,
but a remote message never changes authoritative case state. An application
command must pass the same validation used in standalone mode and then enter the
ledger.

Before a session, verify the scenario version, rule-pack identity and authority
cut-off; agree participant pseudonyms and roles; test local fallback; and state
the certificate boundary. During a session, preserve dissent, avoid revealing
correctness, and record interventions. After submission, separate competency
debrief from case consequences and export the session record.

The Phase A collaboration adapter is bounded and not yet suitable for
unsupervised high-stakes assessment.
