The reference path is local-first, offline-capable and telemetry-free. Networked
group learning is explicit opt-in. Only fictional case data is permitted;
learner identity may be pseudonymous. Exported scenario documents require a
simulation watermark.

Trust controls include strict parsing, versioned ports, append-only
hash-chained events, rule-pack identity, digest-bound certificates,
capability-limited scenario actions and validated command gateways for untrusted
collaboration messages. Assessment-mode hidden reality must not be present in
learner-accessible bundles.

Accessibility is a product requirement, but the current shell has not completed
WCAG conformance testing, assistive-technology testing or an independent
accessibility audit. No production security or accessibility certification is
claimed.
