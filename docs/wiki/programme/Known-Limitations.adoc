== Product and content

* Only one authored company scenario is present.
* CVL and Administration are bounded educational paths, not comprehensive
  practice systems.
* CVA, informal restructuring and compulsory liquidation are intentionally
  shallower alternatives/consequences.
* Rules are a small provisional subset and have not received practitioner
  approval.
* No live case or client data should be entered.

== Assessment

* The rubric and golden runs are developer-authored and not yet supported by a
  completed content-validity or reliability study.
* A certificate is internal evidence of completion and assessed performance,
  not a qualification, licence, JIEB result, statutory authorisation or
  accredited CPD.
* Hidden-state leak detection now exists (`tools/check-hidden-truth.sh`, four
  scan channels plus a reality-versus-kernel drift check, proved by 9/9
  canaries in `tools/test-hidden-truth-scanner.sh`; KEY-003 status
  `mitigated`) but production certificate controls and the detector itself
  still require independent security review.

== Technology

* AffineScript remains experimental and not all intended runtime code has
  migrated from the Zig fallback.
* typed-wasm, native Gossamer, external Burble, VeriSimDB, Authority Watch,
  Hexadeca, Echidna and Stapeln integration are incomplete or capability-gated.
* The local deterministic adapters preserve architecture but are not evidence
  that external services work.
* Between 2026-08-05 and 2026-08-07 this repository's GitHub Actions runs
  (`quality`, `Secret Scanner`) all failed with `startup_failure` — a
  pre-execution failure returning zero jobs in zero seconds. *Root cause
  confirmed and fixed 2026-08-07*: the reusable-caller entry for
  `secret-scanner.yml` had been added under `dependencies:` rather than
  `workflows:` in `.github/workflows/actions.lock`, leaving the lockfile
  unparseable (`cannot unmarshal !!seq into lockfile.Action`). The earlier
  Actions-budget hypothesis recorded here was wrong. Two consequences worth
  keeping: no CI result from that window carries any evidential weight, and
  `gh pr checks` cannot report this class of failure at all — use
  `gh run list`. An owned-compute Bag integration remains planned as a
  longer-term mitigation, independently of this fix.

== Programme and delivery

* Professional, assessment, accessibility, privacy/client and operational
  reviewers are not yet appointed.
* No pilot, price, contract, service level, support commitment or release date
  is available.
* The 18-month pilot horizon is indicative and exposed to reviewer capacity,
  authority change, toolchain gaps and solo-maintainer overload.

== Validation rule

Limitations are removed only when named evidence and review demonstrate that
the condition has changed. Aspirational documentation or a closed issue is not
enough.
