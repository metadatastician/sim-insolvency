Gate pages are durable evidence checklists. The matching GitHub issue coordinates
the decision but cannot replace this record. Every decision must state entry
criteria, reviewed evidence, reviewers, unresolved risks, linked event chains,
outcome, date and conditions. Until that record exists, the gate is open.
